PHONE SE APK BANANE KE STEPS
1. github.com pe free account banao (browser me "Desktop site" ON karo).
2. New repository banao (naam: AutoClicker, Public).
3. "uploading an existing file" pe click karo, is ZIP ko extract karke saare folders/files upload karo
   (important: .github folder bhi upload hona chahiye). Commit karo.
   Agar phone se .github folder upload na ho: "Add file > Create new file" me naam
   .github/workflows/build.yml likho aur build.yml ka content paste karo.
4. Upar "Actions" tab kholo > "Build APK" > build green hone ka wait karo (3-5 min).
5. Build pe click karo > neeche "Artifacts" me AutoClicker-APK download karo (ZIP), extract karo -> app-debug.apk.
6. APK install karo (Unknown sources allow karna hoga).
7. Android 13+: Settings > Apps > Simple AutoClicker > 3 dots > "Allow restricted settings",
   phir Settings > Accessibility me ON karo.
